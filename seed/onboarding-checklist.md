# New starter onboarding checklist

## Before day one
- [ ] Laptop ordered and accounts requested
- [ ] Buddy assigned

## Week one
- [ ] Read **Getting started with the Knowledge Hub**
- [ ] Read **How the service registry works** and **Knowledge Hub architecture overview**
- [ ] Run the sample application locally with `npm start`
- [ ] Ask an admin to send you an invitation, then create a personal API token on your profile page

## Month one
- [ ] Ship a small change behind a feature flag
- [ ] Join the on-call rotation as a shadow and read the **Incident runbook**
