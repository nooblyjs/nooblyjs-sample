Knowledge Hub architecture overview

The Knowledge Hub is a single Node.js process. All backend capability comes from the NooblyJS Core service registry; the application adds a thin domain layer and a Bootstrap user interface.

Layers

  • Routes under /api/v1 validate input and check permissions.
  • Domain services such as the library service combine core services: filing stores files, the data service stores metadata, caching speeds up reads.
  • Activities run in worker threads and must be pure: data in, data out.

Durability

Most default providers keep data in memory. A snapshot written to the filing service every few minutes, and on shutdown, restores the library after a restart.
